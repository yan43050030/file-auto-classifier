# 文件自动分类工具 (File Auto Classifier)

一个带图形界面的 Windows 小工具,两种工作模式:

- **按人归档**:自动解压压缩包(支持多级嵌套、分卷、AES 加密),再按人员名单(姓名 / 身份证号 / 曾用名任一命中)把文件按人归档,并生成"人员 × 来源单位"反馈核对表。
- **文件整理**:把下载目录、移动硬盘里积攒多年的杂乱文件按**类型 + 时间**整理好,同时挑出**重复文件、旧版本、垃圾文件**,给出整理报告。全过程记入台账,**可一键撤销**。

典型场景:向多个单位查询多名人员的信息,各单位以压缩包反馈;本工具一键把所有反馈按"一人一个文件夹"归档,同时标注每份材料来自哪个单位,并列出哪些单位对哪些人还没有反馈。

## 功能特性

### 解压
- **多格式**:zip(含 **AES 加密**,通过 pyzipper)/ 7z / rar / tar / tar.gz / gz;内置官方 UnRAR.exe,打包成 exe 后目标电脑无需安装 WinRAR。
- **多级嵌套**:压缩包里套压缩包(最多 5 层)自动递归解压。
- **分卷识别**:`.part1.rar` 自动带出后续卷、`.7z.001` 分卷直接支持,后续卷不再误报失败。
- **加密压缩包**:密码本自动尝试(输入文件夹里的 txt 自动识别,兼容 `文件名: 密码` 等格式),失败再弹框;验证密码只解压包内最小的一个文件,大包不再整包试错。
- **安全**:防 zip slip 路径穿越;Windows 超长路径(>260 字符)自动处理;解压失败的包收进"解压失败"文件夹,绝不悄悄丢文件。

### 分类
- **人员名单**:每行一个人 `姓名,身份证号,曾用名…`,任一标识命中都归入同一文件夹 —— 不同单位有的按姓名、有的按证号命名文件也不会"分家";支持从 Excel 导入名单;同名人员自动用证号后 4 位区分文件夹。
- **最长匹配优先**:名单同时有"张三"和"张三丰"时,张三丰的文件不会误归给张三。
- **企业识别**:查企业账户/纳税信息时,按 **公司名称** 或 **统一社会信用代码** 归档;名单里写 `公司名称,信用代码` 即可,不写名单也能自动识别。同一批文件中名称与代码同时出现即自动关联,只写名称或只写代码的文件都归入「公司名称_信用代码」;信用代码按 **GB 32100 三重校验**(登记部门/类别码 + 组织机构代码校验位 + 整体校验位),银行/税务等反馈单位不会被误当企业。
- **身份证号识别**:未命中名单的文件,按文件名中的身份证号自动归类;18 位号码做 **GB 11643 校验位验证**(订单号等 18 位数字不再误判),支持 15 位老号码并自动与 18 位互认。
- **一人一个文件夹,按资料类型细分**:同一人/企业不管分几个压缩包、几次反馈,都归进同一个文件夹,里面分「疑似空值 / 银行流水 / 其他数据」,来源单位写成文件名前缀【单位】(旧的"按单位建子文件夹"仍可选)。
- **精简文件名(可选,默认开)**:「【单位】信息_姓名_证号」,去掉文号/批次号/乱码,原名记入《文件名对照表》,不影响重复导入识别。
- **同步归档记录**:在结果目录里手动挪动/改名/删除文件后一键同步(导入前也自动同步),核对表、文件名对照表始终反映现在的实际位置。
- **归档库(可反复导入)**:新反馈直接导入到原结果目录 —— 同一人/企业并入原文件夹(按证号/信用代码、名称对齐,只有名字的旧文件夹会补全为「姓名_证号」),重复导入的相同文件自动跳过,反馈核对表按历次导入累计;可「固定此目录为归档库」。
- **反馈核对表**:自动生成"人员 × 单位"矩阵(CSV + xlsx,空格标黄),哪个单位没反馈哪个人一目了然。
- **内容匹配(可选)**:文件名未命中时,读取 Excel / Word / PDF / 文本内容查找名单中的人;支持旧版 .doc / .xls(Office 97-2003);智能识别与身份证号兜底同样作用于内容。
- **Excel 按人拆分(可选)**:一个表里有多个人的行时,按行拆成每人一份,原表保留在"原始反馈"。
- **内容去重(可选)**:同一人员文件夹内,多个单位反馈的相同文件只留一份。
- **疑似空值(仅银行/支付类反馈)**:"查无账户"之类的小反馈(默认 ≤10 KB,可调)放入此人目录下的「疑似空值」子文件夹,看材料时先跳过、需要时再核对;判定会看内容(只有表头 / 只写了"无" / 正文"查无记录"),有真实记录的小表格照常归档;核对表中以「疑似空」(灰)标出,与"未反馈"(黄)区分。

### 文件整理
- **保护代码/工程目录**:含 `.git`、`package.json`、`requirements.txt`、`pom.xml`、`*.sln` 等标志的目录**整体搬运不打散**,内部结构与隐藏文件原样保留 —— 否则一个代码项目会被按类型拆碎而彻底废掉。
- **按用途分类**:文档 / 表格 / 演示 / PDF / 图片 / 视频 / 音频 / 压缩包 / 安装程序 / 电子书 / 代码 / 设计源文件 / 字体… 按"怎么用"而非扩展名归类。
- **按真实日期归类**:照片优先用 EXIF 拍摄时间,其次解析文件名里的日期(`IMG_20180712`、`微信图片_20230815…`、`2021-03-08…`),都没有才用修改时间 —— 避免"从硬盘拷回来的老照片全被归到今年"。
- **目录布局可选**:`{类别}/{年}`、`{年}/{类别}`、`{类别}/{年月}`、`{来源}/{类别}`、`{原目录}/{类别}`(保留原文件夹名)、`{类别}/{大小档}`,也可自由组合占位符。
- **顺带解开压缩包(可选)**:zip/rar/7z 里的文件解出来一起整理,按所在压缩包名归档;压缩包本身仍照常归类,撤销时解出的文件会被清掉。
- **整理历史**:每次整理记入 `整理历史.db`,可按文件名查"这个文件当初在哪、被整理到哪去了"。
- **来源识别**:微信文件、QQ文件、截图、相机照片、未完成下载,靠命名特征自动认出。
- **重复文件**:内容相同的只留一份(优先留你原本就有的、非副本、时间早的原件;顺带解开的压缩包内容不会抢占"原件"),其余归入「重复文件」并算出可省空间;大文件先比前 64KB 预筛,不做全盘读取;**默认只查 10KB 以上的文件**(空模板/配置文件内容相同是常态,查重只会添乱),门槛可调。
- **体检桶带来源**:「重复文件」「旧版本」内按**原目录名**分层,一眼看出文件是从哪来的,便于核对。
- **旧版本归并**:`报告(1)`、`报告 - 副本`、`方案-最终版2`、`方案_v2` 识别为同一版本族,最新的留在原分类,旧的归入「旧版本」(裸数字结尾如"会议纪要2"不会误判)。
- **垃圾清理**:Thumbs.db / .DS_Store / `~$` 临时文件 / 未完成下载 / 空文件,归入「可清理」分类型摆好;`__init__.py`、`.gitkeep` 等**有意义的空文件不会被当垃圾**。
- **只体检不整理**:先跑一遍看看"有什么问题"(多少重复/垃圾/旧版本、各类型占用),一个文件都不动,看完报告再决定要不要整理。
- **一键清理**:核对完「可清理 / 重复文件 / 旧版本」后,可选择性地把它们移入回收站腾出空间;只删整理台账里记录过、由本工具放进去的文件,正常分类的文件和你自己放进去的文件都不受影响;清理也记入台账,撤销时会提示从回收站找回。
- **整理报告**:总览、各文件夹占用、类型分布、年份分布、最大的 20 个文件(CSV + xlsx)。
- **一键撤销**:默认"移动"(整理硬盘不占额外空间),每一步写入撤销台账,随时可把文件全部还原回原位置,整理时新建的空分类目录一并清掉;台账边做边写,中途崩溃也能撤销已完成的部分。

### 易用性
- **试运行预览**:先列出"哪个文件 → 哪个文件夹"清单,确认后再执行;发现分错的可在预览里**双击直接改归属**(支持多选批量改),当场修正再执行。
- **进度条 + 可取消**;日志同时写入输出目录 `分类日志_时间.txt`。
- **拖拽添加**:压缩包 / 文件夹直接拖进窗口。
- **配置记忆**:名单、选项自动保存;输出目录默认跟随最后添加的压缩包所在目录(手动改过则保持);支持保存 / 加载任务模板(同一批人查多轮直接复用)。
- **命令行模式**:带参数运行即无界面批处理,可配合计划任务自动处理固定收件目录(`-h` 查看用法)。
- **高分屏清晰**:PySide6(Qt)界面,适配 Windows 125% / 150% / 200% 缩放。

## 直接运行(需 Python 3.8+)

```bash
# 界面依赖 PySide6;其余第三方依赖都是可选的,缺什么降级什么
pip install -r requirements.txt
python 文件自动分类工具.py            # 图形界面
python 文件自动分类工具.py -h         # 命令行用法
```

文件整理示例:

```bash
python 文件自动分类工具.py --mode organize -i D:\下载 -o D:\整理结果
python 文件自动分类工具.py --mode organize -i E:\ -o E:\整理 --layout "{年}/{类别}"
python 文件自动分类工具.py --list-layouts                       # 查看内置布局
python 文件自动分类工具.py --undo "D:\整理结果\整理台账_20240115_103000.jsonl"
```

命令行示例:

```bash
python 文件自动分类工具.py -i 收件目录 -o 结果目录 --roster 名单.xlsx --content-match
python 文件自动分类工具.py -i a.zip b.rar -o out --kw 张三 --kw "李四,110101199003078515"
```

## 打包成免安装 EXE

```bash
pip install pyinstaller -r requirements.txt

pyinstaller --onefile --windowed --name 文件自动分类工具V5.0 ^
  --icon app.ico --add-data "app.ico;." --add-binary "UnRAR.exe;." ^
  --collect-submodules py7zr --collect-submodules rarfile --collect-submodules pyzipper ^
  --collect-submodules send2trash --collect-submodules openpyxl ^
  --hidden-import multivolumefile --hidden-import inflate64 --hidden-import pybcj ^
  --hidden-import pyppmd --hidden-import brotli ^
  文件自动分类工具.py
```

生成的 `dist/文件自动分类工具V5.0.exe` 拷到任意 Windows 电脑双击即用,无需安装 Python 或 WinRAR。
(如不需要 Word/PDF 内容匹配,可不装 python-docx / pdfplumber,体积更小。)

> 每次发版由 GitHub Actions 在 Windows 环境自动跑完测试后打包,
> 可直接到 [Releases](../../releases) 下载免安装 exe。

## 代码结构

| 位置 | 说明 |
| --- | --- |
| `文件自动分类工具.py` | 入口:双击开界面,带参数走命令行 |
| `fac/extract.py` | 解压(多格式 / 嵌套 / 分卷 / 密码 / 防穿越) |
| `fac/roster.py` | 人员名单(多标识合并、最长匹配、Excel 导入) |
| `fac/pipeline.py` | 主流程调度(预览 / 进度 / 取消 / 去重 / 单位标注) |
| `fac/idcard.py` | 身份证号校验(18 位校验位 / 15 位 / 互转) |
| `fac/naming.py` | 文件名精简(去文号/批次号/乱码,信息在前) |
| `fac/gui_tips.py` | 各功能的鼠标悬停说明 |
| `fac/library.py` | 归档库(并入已有文件夹 / 重复导入跳过 / 归档记录与累计核对表) |
| `fac/doctype.py` | 资料类型判定(银行流水 / 其他数据) |
| `fac/emptyfile.py` | 疑似空值反馈识别(小文件 + 表格无数据行 / 正文"查无记录") |
| `fac/company.py` | 企业识别(统一社会信用代码校验 / 公司名称提取 / 名称↔代码关联) |
| `fac/password.py` | 密码管理与密码本解析 |
| `fac/content_match.py` | Excel/Word/PDF/文本 内容匹配 |
| `fac/excel_split.py` | Excel 按人拆分 |
| `fac/report.py` | 人员 × 单位 反馈核对表 |
| `fac/organize.py` | 文件整理模式(类型+时间布局、体检、撤销台账) |
| `fac/filetypes.py` | 文件类型 / 来源 / 垃圾 / 副本标记词表 |
| `fac/health.py` | 文件体检(重复、版本族、垃圾、大文件、空目录) |
| `fac/undo.py` | 撤销台账与还原 |
| `fac/purge.py` | 一键清理(按台账限定范围,删到回收站并补记台账) |
| `fac/filedate.py` | 文件真实日期(EXIF 拍摄时间 / 文件名日期) |
| `fac/history.py` | 整理历史索引与搜索(SQLite) |

| `fac/gui.py` / `fac/cli.py` | 图形界面 / 命令行 |
| `fac/gui_organize.py` / `fac/gui_style.py` | 界面中「文件整理」相关操作 / 界面样式 |
| `fac/gui_bridge.py` | 后台线程 → 界面线程的安全通道(防闪退) |
| `fac/config.py` | 配置记忆与任务模板 |
| `tests/` | 单元测试(`python -m pytest tests/`,含界面无头冒烟) |
| `使用说明.md` | 面向普通用户的详细使用说明 |
| `评估与升级计划.md` | V1.2 评估报告与本次升级的规划 |
| `UnRAR.exe` | RARLAB 官方免费解压器,用于 rar 支持 |

## 隐私说明

本工具处理的往往是公民个人信息:全程本地运行、不联网、不上传任何数据;密码不写入日志;临时文件在任务结束后自动清理。
